# C Programming – Basics for Beginners

Welcome to my **C Programming Basics** repository! 👋

This repository contains simple C programs and examples created while learning the fundamentals of C programming.

## 📚 Topics Covered

- Variables and Data Types
- Input and Output
- Operators
- Conditional Statements
- Loops
- Functions
- Arrays
- Pointers
- File Handling
- Basic Programming Concepts

## 🎯 Purpose

This repository is mainly for beginners who are starting their journey with C programming.  
The programs are kept simple so that the concepts are easy to understand and practice.
